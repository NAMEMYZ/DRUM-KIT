# Drum Kit 🥁

A browser drum kit — click a drum or press a key to play it.

**Live demo:** https://namemyz.github.io/DRUM-KIT/

## Controls
| Key | W | A | S | D | J | K | L |
|---|---|---|---|---|---|---|---|
| Sound | Tom 1 | Tom 2 | Tom 3 | Tom 4 | Crash | Kick | Snare |

## Tech
HTML · CSS · JavaScript (DOM events, Audio API)
